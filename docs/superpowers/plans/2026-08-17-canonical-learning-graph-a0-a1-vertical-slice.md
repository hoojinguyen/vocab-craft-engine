# Canonical Learning Graph A0–A1 Vertical Slice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a separately versioned, provenance-aware canonical learning graph that can publish and validate one reviewed A0–A1 curriculum module as an immutable SQLite/JSON pack.

**Architecture:** Keep the existing V2/V3 staging corpus unchanged as a reference input. A new `learning_graph.duckdb` stores source assets, immutable raw snapshots, candidates, review decisions, canonical revisions, and graph edges; a composer selects only approved revisions and exports a separate mobile pack. The first vertical slice proves source-to-pack traceability with fixtures and an operator CLI, without downloading or publishing any unverified source.

**Tech Stack:** Python 3.11+, DuckDB, SQLite, Pydantic v2, PyYAML, pytest, Black, Ruff.

---

## Scope boundary

- Create the graph engine as `src/learning/`; do not add canonical tables to `src/db/schema.py` or alter the default V2 registry.
- Store graph data at `data/processed/learning_graph.duckdb`; do not mutate `data/processed/staging.duckdb` or `data/output/english_dataset.db`.
- Publish the pilot at `data/output/curriculum/<pack-id>/`; it is separate from `english_dataset.db`, `core_3000.db`, and their existing manifests.
- Support only source registration, raw snapshot import, candidate review, canonical graph creation, composition, validation, and publishing. Audio generation, machine translation, CEFR inference, and learner mastery scheduling are intentionally not part of this slice.
- A source must be explicitly approved with license/use evidence before it can create candidates or published content. No hard-coded GitHub/raw-dataset URL is permitted in this implementation.

## Data contract locked by this plan

`source_assets` is the legal/provenance authority. `raw_reference_records` is append-only and records the exact source payload hash. `content_candidates` are reviewable proposals. `canonical_content` holds stable IDs; `content_revisions` holds immutable versioned payloads; `content_edges` describes prerequisite, coverage, scenario, dialogue, and activity relationships. `content_reviews` is the only route to an `approved` revision.

All IDs are UUID strings generated by the engine except external source identifiers. JSON is serialized with sorted keys, UTF-8, and compact separators before hashing. Candidate/revision hashes are SHA-256 hex digests. The only supported review states are `candidate`, `approved`, `rejected`, and `quarantined`; a rejected or quarantined revision is never composed into a pack.

```python
# src/learning/models.py
from __future__ import annotations

from enum import StrEnum
import hashlib
import json
from typing import Any

from pydantic import BaseModel, Field, HttpUrl, field_validator, model_validator


def canonical_json(value: dict[str, Any]) -> str:
    return json.dumps(value, ensure_ascii=False, sort_keys=True, separators=(",", ":"))


class ReviewState(StrEnum):
    CANDIDATE = "candidate"
    APPROVED = "approved"
    REJECTED = "rejected"
    QUARANTINED = "quarantined"


class ContentType(StrEnum):
    MODULE = "module"
    OBJECTIVE = "objective"
    LEXEME = "lexeme"
    SENSE = "sense"
    FORM = "form"
    CHUNK = "chunk"
    PATTERN = "pattern"
    SENTENCE = "sentence"
    AUDIO_ASSET = "audio_asset"
    SCENARIO = "scenario"
    DIALOGUE_TURN = "dialogue_turn"
    ACTIVITY_TEMPLATE = "activity_template"
    ASSESSMENT_CRITERION = "assessment_criterion"
    ACTIVITY = "activity"


class SourceAssetInput(BaseModel):
    asset_id: str = Field(pattern=r"^[a-z0-9][a-z0-9._-]{2,127}$")
    title: str = Field(min_length=1)
    locator: HttpUrl
    asset_version: str = Field(min_length=1)
    sha256: str = Field(pattern=r"^[0-9a-f]{64}$")
    license_id: str
    license_url: HttpUrl
    attribution: str
    redistribution_allowed: bool
    validation_status: ReviewState = ReviewState.CANDIDATE

    @model_validator(mode="after")
    def approved_assets_have_rights_evidence(self) -> "SourceAssetInput":
        if self.validation_status is ReviewState.APPROVED and (
            not self.redistribution_allowed or not self.license_id.strip() or not self.attribution.strip()
        ):
            raise ValueError("license_id, attribution, and redistribution_allowed are required for approval")
        return self


class ContentRevisionInput(BaseModel):
    stable_key: str = Field(pattern=r"^[a-z0-9][a-z0-9._-]{2,127}$")
    content_type: ContentType
    payload: dict[str, Any]
    payload_sha256: str = ""

    @field_validator("payload")
    @classmethod
    def payload_must_not_be_empty(cls, value: dict[str, Any]) -> dict[str, Any]:
        if not value:
            raise ValueError("payload must not be empty")
        return value

    @model_validator(mode="after")
    def calculate_payload_hash(self) -> "ContentRevisionInput":
        self.payload_sha256 = hashlib.sha256(canonical_json(self.payload).encode("utf-8")).hexdigest()
        return self
```

```python
# src/learning/store.py
from __future__ import annotations

from contextlib import contextmanager
from pathlib import Path
import threading
from typing import Any, Iterator

import duckdb

from src.learning.schema import MIGRATIONS


class LearningGraphStore:
    def __init__(self, db_path: Path) -> None:
        self.db_path = Path(db_path)
        self._conn: duckdb.DuckDBPyConnection | None = None
        self._lock = threading.RLock()

    def connection(self) -> duckdb.DuckDBPyConnection:
        with self._lock:
            if self._conn is None:
                self.db_path.parent.mkdir(parents=True, exist_ok=True)
                self._conn = duckdb.connect(str(self.db_path))
                self._conn.execute("PRAGMA threads = 1")
            return self._conn

    def initialize(self) -> None:
        conn = self.connection()
        conn.execute("CREATE TABLE IF NOT EXISTS graph_schema_migrations (version INTEGER PRIMARY KEY, applied_at TIMESTAMP NOT NULL DEFAULT current_timestamp)")
        current = conn.execute("SELECT coalesce(max(version), 0) FROM graph_schema_migrations").fetchone()[0]
        latest = MIGRATIONS[-1][0]
        if current > latest:
            raise RuntimeError(f"graph schema version {current} is newer than this engine ({latest})")
        for version, sql in MIGRATIONS:
            if version > current:
                conn.execute("BEGIN TRANSACTION")
                try:
                    conn.execute(sql)
                    conn.execute("INSERT INTO graph_schema_migrations(version) VALUES (?)", [version])
                    conn.execute("COMMIT")
                except Exception:
                    conn.execute("ROLLBACK")
                    raise

    @contextmanager
    def transaction(self) -> Iterator[duckdb.DuckDBPyConnection]:
        with self._lock:
            conn = self.connection()
            conn.execute("BEGIN TRANSACTION")
            try:
                yield conn
                conn.execute("COMMIT")
            except Exception:
                conn.execute("ROLLBACK")
                raise

    def fetch_value(self, sql: str, params: list[Any] | None = None) -> Any:
        row = self.connection().execute(sql, params or []).fetchone()
        return row[0] if row else None

    def close(self) -> None:
        with self._lock:
            if self._conn is not None:
                self._conn.close()
                self._conn = None
```

```python
# src/learning/catalog.py
from __future__ import annotations

import hashlib
from typing import Any
from uuid import uuid4

from src.learning.models import ReviewState, SourceAssetInput, canonical_json
from src.learning.store import LearningGraphStore


class SourceCatalog:
    def __init__(self, store: LearningGraphStore) -> None:
        self.store = store

    def register(self, source: SourceAssetInput) -> None:
        with self.store.transaction() as conn:
            existing = conn.execute("SELECT sha256 FROM source_assets WHERE asset_id = ?", [source.asset_id]).fetchone()
            if existing and existing[0] != source.sha256:
                raise ValueError(f"source asset '{source.asset_id}' already exists with a different checksum")
            conn.execute(
                "INSERT INTO source_assets VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, current_timestamp) ON CONFLICT(asset_id) DO NOTHING",
                [source.asset_id, source.title, str(source.locator), source.asset_version, source.sha256,
                 source.license_id, str(source.license_url), source.attribution,
                 source.redistribution_allowed, source.validation_status.value],
            )

    def append_raw_record(self, asset_id: str, external_key: str, record_type: str, payload: dict[str, Any], import_run_id: str) -> str:
        encoded = canonical_json(payload)
        payload_sha256 = hashlib.sha256(encoded.encode("utf-8")).hexdigest()
        status = self.store.fetch_value("SELECT validation_status FROM source_assets WHERE asset_id = ?", [asset_id])
        if status != ReviewState.APPROVED.value:
            raise ValueError(f"source asset '{asset_id}' is not approved for candidate creation")
        existing = self.store.fetch_value(
            "SELECT raw_record_id FROM raw_reference_records WHERE asset_id = ? AND external_key = ? AND payload_sha256 = ?",
            [asset_id, external_key, payload_sha256],
        )
        if existing:
            return existing
        raw_record_id = str(uuid4())
        with self.store.transaction() as conn:
            conn.execute(
                "INSERT INTO raw_reference_records(raw_record_id, asset_id, external_key, record_type, payload_json, payload_sha256, import_run_id) VALUES (?, ?, ?, ?, ?, ?, ?)",
                [raw_record_id, asset_id, external_key, record_type, encoded, payload_sha256, import_run_id],
            )
        return raw_record_id
```

- [ ] **Step 3: Implement canonical lifecycle methods with no update/delete path**

The exact public API in `src/learning/repository.py` is:

```text
create_candidate(raw_record_id: str, content_type: str, payload: dict, evidence: dict, confidence: float) -> str
review_candidate(candidate_id: str, decision: str, reviewer_id: str, rationale: str) -> str | None
create_revision(prior_revision_id: str, payload: dict, reviewer_id: str, rationale: str) -> str
add_edge(from_revision_id: str, to_revision_id: str, relation_type: str, attributes: dict | None = None) -> str
get_revision(revision_id: str) -> dict[str, object]
get_latest_approved_revision(stable_key: str) -> str
```

Implement `create_candidate()` by first confirming that `raw_record_id` exists, then joining it to an approved `source_assets` row; otherwise raise `ValueError("raw record is missing or source is not approved")`. from dataclasses import dataclass, field
```python
from typing import Any


@dataclass(frozen=True)
class GateFailure:
    code: str
    message: str
    revision_id: str | None = None


@dataclass
class GateReport:
    failures: list[GateFailure] = field(default_factory=list)

    @property
    def passed(self) -> bool:
        return not self.failures

    def add(self, code: str, message: str, revision_id: str | None = None) -> None:
        self.failures.append(GateFailure(code, message, revision_id))


class QualityGate:
    def validate_revision(self, revision: dict[str, Any]) -> GateReport:
        report = GateReport()
        payload = revision["payload"]
        revision_id = revision.get("revision_id")
        if revision["review_state"] != "approved":
            report.add("revision.not_approved", "Only approved revisions may be published", revision_id)
        if not payload.get("stable_key"):
            report.add("revision.stable_key_missing", "A stable_key is required", revision_id)
        return report

    def validate_graph(self, revisions: list[dict[str, Any]], edges: list[dict[str, Any]]) -> GateReport:
        report = GateReport()
        for revision in revisions:
            report.failures.extend(self.validate_revision(revision).failures)
        return report

    def summarize(self, revisions: list[dict[str, Any]]) -> dict[str, dict[str, int]]:
        summary = {"review_states": {}, "source_assets": {}, "cefr_levels": {}}
        for revision in revisions:
            payload = revision["payload"]
            for bucket, value in (
                ("review_states", revision["review_state"]),
                ("source_assets", revision.get("source_asset_id", "unknown")),
                ("cefr_levels", payload.get("cefr_level", "unassigned")),
            ):
                summary[bucket][value] = summary[bucket].get(value, 0) + 1
        return summary
```

```python
@dataclass(frozen=True)
class PackExportResult:
    output_dir: Path
    sqlite_path: Path
    json_path: Path
    manifest_path: Path
    sha256_path: Path


def export(self, pack: PackGraph, output_dir: Path) -> PackExportResult:
    if not bool(pack.quality_report["passed"]):
        raise ValueError("quality gates failed; pack cannot be published")
    destination = Path(output_dir)
    if destination.exists():
        raise FileExistsError(destination)
    destination.parent.mkdir(parents=True, exist_ok=True)
    temporary_dir = Path(tempfile.mkdtemp(prefix=f".{pack.pack_id}-", dir=destination.parent))
    try:
        sqlite_path = temporary_dir / "curriculum.db"
        self._write_sqlite(sqlite_path, pack)
        self._verify_sqlite(sqlite_path)
        json_path = temporary_dir / "curriculum.json"
        json_path.write_text(canonical_json({
            "pack_id": pack.pack_id,
            "version": pack.version,
            "revisions": list(pack.revisions),
            "edges": list(pack.edges),
        }), encoding="utf-8")
        manifest_path = self._write_manifest(temporary_dir, pack, [sqlite_path, json_path])
        sha256_path = temporary_dir / "curriculum.db.sha256"
        sha256_path.write_text(f"{self._sha256(sqlite_path)}  curriculum.db\\n", encoding="utf-8")
        for file_path in (sqlite_path, json_path, manifest_path, sha256_path):
            with file_path.open("rb") as handle:
                os.fsync(handle.fileno())
        temporary_dir.replace(destination)
        return PackExportResult(destination, destination / "curriculum.db", destination / "curriculum.json", destination / "manifest.json", destination / "curriculum.db.sha256")
```

```python
def _sha256(self, path: Path) -> str:
    digest = hashlib.sha256()
    with path.open("rb") as handle:
        for block in iter(lambda: handle.read(65_536), b""):
            digest.update(block)
    return digest.hexdigest()


def _verify_sqlite(self, path: Path) -> None:
    connection = sqlite3.connect(path)
    try:
        if connection.execute("PRAGMA integrity_check").fetchone()[0] != "ok":
            raise ValueError("SQLite integrity_check failed")
        if connection.execute("PRAGMA foreign_key_check").fetchall():
            raise ValueError("SQLite foreign_key_check failed")
    finally:
        connection.close()


def _write_sqlite(self, path: Path, pack: PackGraph) -> None:
    connection = sqlite3.connect(path)
    try:
        connection.execute("PRAGMA foreign_keys = ON")
        connection.executescript(CURRICULUM_PACK_SCHEMA)
        connection.executemany(
            "INSERT INTO content_revisions VALUES (?, ?, ?, ?, ?, ?, ?)",
            [(item["revision_id"], item["content_id"], item["stable_key"], item["content_type"], item["revision_number"], item["payload_json"], item["payload_sha256"]) for item in pack.revisions],
        )
        connection.executemany(
            "INSERT INTO content_edges VALUES (?, ?, ?, ?, ?)",
            [(edge["edge_id"], edge["from_revision_id"], edge["to_revision_id"], edge["relation_type"], edge["attributes_json"]) for edge in pack.edges],
        )
        connection.executemany(
            "INSERT INTO source_attributions VALUES (?, ?, ?, ?, ?, ?)",
            [(item["asset_id"], item["title"], item["license_id"], item["license_url"], item["attribution"], item["sha256"]) for item in pack.source_attributions],
        )
        connection.execute("INSERT INTO pack_metadata VALUES ('pack_id', ?)", [pack.pack_id])
        connection.execute("INSERT INTO pack_metadata VALUES ('version', ?)", [pack.version])
        connection.execute("INSERT INTO pack_metadata VALUES ('graph_schema_version', '1')")
        connection.execute("INSERT INTO quality_gate_results VALUES ('pack.quality', ?, ?, NULL)", [int(bool(pack.quality_report["passed"])), json.dumps(pack.quality_report, ensure_ascii=False, sort_keys=True)])
        connection.commit()
    finally:
        connection.close()


def _write_manifest(self, directory: Path, pack: PackGraph, files: list[Path]) -> Path:

        "quality_gates": pack.quality_report, "files": file_entries,
    }
    manifest_path = directory / "manifest.json"
    manifest_path.write_text(json.dumps(manifest, ensure_ascii=False, sort_keys=True, indent=2), encoding="utf-8")
```

```python
        if not source_path.exists():
            raise FileNotFoundError(source_path)
        conn = duckdb.connect(str(source_path), read_only=True)
        try:
            rows = conn.execute("SELECT id, lemma, pos, source FROM words ORDER BY id").fetchall()
        finally:
            conn.close()
        for word_id, lemma, pos, source in rows:
            self.catalog.append_raw_record(
                asset_id=asset_id,
                external_key=f"legacy-word:{word_id}",
                record_type="legacy_word",
                payload={"id": word_id, "lemma": lemma, "pos": pos, "source": source},
                import_run_id=import_run_id,
            )
        return len(rows)
```

Do not import legacy definitions/sentences in this slice. Add them only after their source-level license and field-quality evidence can be represented in the source catalog. This bridge must never call `DELETE`, `UPDATE`, `VACUUM`, or `init_schema()` against the legacy database.
