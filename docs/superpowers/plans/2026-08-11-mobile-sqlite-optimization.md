# Mobile SQLite Database Optimization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Optimize mobile SQLite database packaging in `vocab-craft-engine` to achieve 35–45% file size reduction and sub-5ms query latency across all core query workloads using stock SQLite.

**Architecture:** Update `SQLiteExporter` to transform staging tables into Integer Enum encoded attributes, `WITHOUT ROWID` link tables, External Content FTS5 indexes, covering indexes, and SQL compatibility views. Include a comprehensive benchmark suite verifying FK integrity and SLA targets.

**Tech Stack:** Python 3.10+, SQLite 3 (native standard library `sqlite3`), pytest.

## Global Constraints

- **Compatibility:** Native stock SQLite (iOS, Android, Flutter, React Native standard sqlite3 binaries). Zero custom C extensions.
- **Data Integrity:** `PRAGMA foreign_key_check` must return zero violations; `PRAGMA integrity_check` must return `ok`.
- **Latency SLA:** Average latency < 5.0 ms across all 4 query benchmarks (Lemma Lookup, FTS Search, Reflex Sampling, Topic/Relation JOINs).
- **Compression Target:** Database size reduction >= 30% compared to unoptimized export.

```python
def benchmark_all_queries(self, iterations: int = 100) -> Dict[str, float]:
    """
    Runs automated SLA performance benchmarks for core query workloads.
    Target: < 5.0 ms per query type.
    """
    conn = sqlite3.connect(str(self.db_path))
    cursor = conn.cursor()
    results = {}

    # 1. Exact Lemma Lookup
    q_lemma = "SELECT id, lemma, pos, cefr_level, ipa_uk FROM words WHERE lemma = 'apple';"
    durations = []
    for _ in range(iterations):
        t0 = time.perf_counter()
        cursor.execute(q_lemma)
        cursor.fetchone()
        durations.append((time.perf_counter() - t0) * 1000.0)
    results["lemma_lookup_ms"] = round(sum(durations) / len(durations), 3)

    # 2. FTS5 Search
    q_fts = "SELECT w.id, w.lemma, w.pos FROM words_fts f JOIN words w ON f.rowid = w.id WHERE words_fts MATCH 'appl*' LIMIT 20;"
    durations = []
    for _ in range(iterations):
        t0 = time.perf_counter()
        cursor.execute(q_fts)
        cursor.fetchall()
        durations.append((time.perf_counter() - t0) * 1000.0)
    results["fts_search_ms"] = round(sum(durations) / len(durations), 3)

    # 3. Indexed Fast Random Sampling for Reflex Drills
    q_reflex = """
        SELECT r.id, r.prompt_text, r.correct_answer, r.distractors_json, s.cefr_level
        FROM reflex_drills r
        JOIN sentences s ON r.sentence_id = s.id
        WHERE r.drill_type = 1
          AND r.id >= (
            SELECT ABS(RANDOM()) % (MAX(id) - MIN(id) + 1) + MIN(id)
            FROM reflex_drills WHERE drill_type = 1
          )
        LIMIT 1;
    """
    durations = []
    for _ in range(iterations):
        t0 = time.perf_counter()
        cursor.execute(q_reflex)
        cursor.fetchone()
        durations.append((time.perf_counter() - t0) * 1000.0)
    results["reflex_sampling_ms"] = round(sum(durations) / len(durations), 3)

    conn.close()
    return results
```
